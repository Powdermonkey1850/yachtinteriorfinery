== Description ==

Gravity Forms Styler for Divi is an all-in-one Divi plugin to add and style your Gravity Forms in Divi effortlessly.

== Installation ==

Upload divi-extended-gravity-forms-styler-x.x on your website from the WordPress Dashboard and activate it.

Gravity Forms Styler module will be added on page builder module list.

Go to a page, edit it using Divi builder and add the module. Once the module is added to the page, use the module settings to select content and format the module. For detailed setup and customization process, please visit the documentation page: https://diviextended.com/documentation/gravity-forms-styler-for-divi/

== Frequently Asked Questions ==

= What is Gravity Form Styler for Divi? =
Gravity Forms Styler for Divi is a plugin that adds a new module in Divi theme builder for styling Gravity Forms.
